@seikou/bdmv/PlayItem

PlayItem

An interface in @seikou/bdmv.

interface PlayItem {
  readonly clipId: string;
  readonly connectionCondition: number;
  readonly inTime: number;
  readonly outTime: number;
  readonly stillMode: number;
  readonly angleClipIds: readonly string[];
  readonly stn: StnTable;
}

One item of a playlist's main path: a clip, the stretch of it that plays, and the streams that can be picked while it does.

Fields

NameTypeDescription
clipIdstringclip[0].clip_id: the 5-digit name of the clip, BDMV/CLIPINF/<clipId>.clpi and BDMV/STREAM/<clipId>.m2ts.
connectionConditionnumberconnection_condition: how this item joins the previous one, 1 for a non-seamless join, 5 and 6 for seamless joins.
inTimenumberin_time: where the item starts, in 45 kHz clip time.
outTimenumberout_time: where the item ends, in 45 kHz clip time (exclusive).
stillModenumberstill_mode: 0 for no still, 1 for a still of stillTime seconds, 2 for an infinite still.
angleClipIdsreadonly string[]clip[1..].clip_id: the clips of angles 2 and up, in order; empty for single-angle items.
stnStnTablestn: the streams selectable while this item plays.
