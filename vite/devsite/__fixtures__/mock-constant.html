Matroska / EBML element ids used by the writer, written with their length-marker bits as they appear in the file (so a 4-byte id such as Segment has its first byte's top bits set). Each entry names the element and the section that defines it: RFC 9559 (Matroska) for the Segment and everything inside it, RFC 8794 (EBML) for the header elements and Void. Ids were checked against the RFC text. idBytes in ebml.ts turns one into its bytes.
