Build on Seikou’s Blu-ray code

Eight TypeScript packages that read a disc’s files, demux its streams, draw its subtitles and play it in a browser. Every function here has an example the tests run.

Put the player in a pageThe integration guide: the engine worker, the controller and a disc from files or a server.

Reading and playing media

  • @seikou/bdmvThe Blu-ray disc format, read without a player.
  • @seikou/pgPresentation Graphics (PG), the Blu-ray bitmap subtitles, ported from libbluray.
  • @seikou/assAn ASS/SSA subtitle renderer ported from libass 0.17.5.
  • @seikou/engineThe Blu-ray player engine for browsers.
  • @seikou/matroskaMatroska and WebM reading and writing for any JavaScript host: Node, browsers and workers (no node: imports, no Buffer).

Running a disc library

  • @seikou/nasThe wire contract between Seikou’s NAS server, the player and the pairing Worker.
  • @seikou/titlesNaming a disc library.
  • @seikou/fansubsFinding and timing fansub subtitles for a disc.
