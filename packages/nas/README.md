# @seikou/nas

The wire contract between Seikou's NAS server, the player and the pairing Worker, as types and small pure functions with no I/O: the NAS API's request and response types (`nas-api`), disc keys and TheDiscDB's content hash (`content-hash`), the rules for saved playback places (`place-rules`), encode titles, ids and place keys (`encode-title`, `encode-id`, `place-key`), title text, pairing codes, the CORS policy and the WebRTC data-channel framing (`rtc-wire`). It exists so the three sides agree by sharing one definition instead of copies, and it needs nothing provided by its consumer.
