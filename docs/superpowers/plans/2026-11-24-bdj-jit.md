# BD-J JIT, first slice — Plan

Spec: `docs/superpowers/specs/2026-11-24-bdj-jit-design.md`. Branch `bdj-jit`.

## Task 1: runtime seam in the interpreter

- `packages/bdj/src/jvm/loader.ts`: `JMethod.jit` (`CompiledMethod | null | undefined`) and `JMethod.heat`, initialised
  where methods are made (loader, `natives/invoke.ts`).
- `packages/bdj/src/jvm/interpreter.ts`: move the inner loop's catch into `caught(jvm, t, f, e, sp)`; export a
  `JitRuntime` object (`jitRuntime`) with the helpers compiled code calls; in `run`'s outer loop, compile at the heat
  threshold and dispatch to the compiled function; count taken backward branches and hop to the outer loop once the
  method is hot or compiled.
- `packages/bdj/src/jvm/jvm.ts`: `JvmOptions.jit` (`'off' | 'on' | 'force'`), the `new Function` probe, the threshold,
  `jitStats()`.
- Test: the existing interpreter, threads and conformance tests pass unchanged with the JIT off.

## Task 2: the compiler

- `packages/bdj/src/jvm/jit.ts`: `analyse(m)` (instruction starts, stack depth per pc, leaders, refusals),
  `generate(m, analysis)` (JS source), `compileMethod(m, rt)`.
- Tests (`jit.test.ts`, written first): refusal of `jsr`; depth table on a small method; compiled vs interpreted
  results on assembled methods; exceptions caught in the frame and in a caller with the right pc; budget equivalence;
  a blocked `monitorenter`; `<clinit>` from compiled code; the CSP probe.

## Task 3: conformance with the JIT forced

- Split `tests/bdj/conformance.test.ts` into `conformance-cases.ts` (`defineConformance(jit)`) and two test files
  (`conformance.test.ts` with the default, `conformance-jit.test.ts` with `'force'`), asserting no compile failed.

## Task 4: plumbing and the test flag

- `runBdjWorker` options and `BdjRuntimeDeps` take `jit`; `bdj-worker-entry.ts` reads `nojit` from its worker name;
  `seikouBdjProvider` names the BD-J worker with the engine worker's flags; `src/ui/App.tsx` passes `?nojit=1`.
- `tests/bdj/replay-player.ts` takes a `jit` option (and `BDJ_JIT` in the environment for manual runs).

## Task 5: measure and tune

- Node: `tests/bdj/bench-startup.ts` (CPU time, first `selectPlaylistN`) for thresholds and before/after.
- Browser: headless Chromium, `?nojit=1` against the default, cold and warm, several runs each (port 4193).
- Golden checks: `tests/bdj/*`, `tests/local/bdj-menus.test.ts`, `tests/local/bdj-boot.test.ts` with the JIT default
  and forced.

## Task 6: docs

- CLAUDE.md (BD-J paragraph, the `?nojit=1` flag), `docs/known-issues.md` (start-up numbers, JIT notes), 
  `docs/roadmap.md` (row updated to what remains), the 5c spec's §4.7 status, this spec's §9.
