# Milestone 4a: PGS and SRT Subtitles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Disc PG subtitles (any stream, forced captions always) and user-loaded SRT files with offset and size, drawn on the player canvas and verified against libbluray.

**Architecture:** libbluray's PG decoding (`pg_decode.c`, the PG branch of `graphics_processor.c`) and PG rendering (`_render_pg` and its helpers from `graphics_controller.c`) are ported into the engine. A `PgStreamControl` picks the PID from PSR2 like `_find_pg_stream`, queues PG units, and presents display sets at their PTS into a double-buffered PG `OverlayPlane`. SRT is parsed and drawn in the engine by original code. The compositor draws video → PG → text → IG. The M3 trace harness gains a PG plane hash.

**Tech Stack:** TypeScript (strict), React 19, Vite 8, Vitest 5, Playwright 1.64 (Chrome); C (libbluray 448f896) in Docker for the harness.

**Execution:** native (superpowers:executing-plans: tasks implemented inline in one session, one fresh whole-branch review at the end), chosen by the user on 2026-10-15.

**Spec:** `docs/superpowers/specs/2026-10-15-m4a-pgs-srt-design.md` (parent: `docs/superpowers/specs/2026-10-12-bluray-web-player-design.md`; M3: `docs/superpowers/specs/2026-10-14-m3-hdmv-menus-design.md`). Read all three.

## Global Constraints

- Ported code lives in `src/engine/`, is LGPL-2.1-or-later with the SPDX/copyright header used by `src/engine/bdmv/mpls-parser.ts`, and is listed in `src/engine/NOTICE` with its source. SRT code (`src/engine/subs/`) is original and says so in its header.
- Port from libbluray commit `448f896` only; keep libbluray's names in comments where ours differ.
- Engine code must not import React or anything from `src/ui/` or `src/player/`.
- No new runtime dependencies. Text decoding uses `TextDecoder` (with `fatal: true` for the UTF-8 attempt).
- TypeScript strict with `noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax`; few comments, explaining why; `readonly` interface fields.
- One subtitle choice at a time: a PG stream, the text track, or Off. Forced PG composition objects show whatever is chosen.
- PG queue cap: 64 completed display sets (drop the oldest). Text offset steps: 100 ms. Text scale: 0.5–2.0, steps of 0.1.
- The masked-operation message is exactly `The disc doesn't allow this here.`; the unreadable-SRT notice is exactly `This file has no subtitles we can read`.
- Existing behaviour stays: every existing test keeps passing, and the M3 IG plane keeps its immediate (unbuffered) semantics so M3 goldens do not change.

### Deviations from the spec (decided while planning)

1. **PG rendering is its own class (`graphics/pg-renderer.ts`)**, not an extension of `GraphicsController`. PG must run on discs without a navigator (BD-J, raw playlist picks), where no graphics controller exists. The ported functions are the same; the shared crop step (`_render_composition_object`) moves to `graphics/composition.ts` and both use it.
2. **The PG plane is double-buffered.** libbluray's overlay contract (`decoders/overlay.h`) commits changes at `BD_OVERLAY_FLUSH`; `_render_pg` flushes the new subtitle and then queues clears of the same areas for the next flush. `OverlayPlane` gains a `buffered` mode (operations go to a back buffer; `flush` copies it to the visible one), used for PG on both our side and the harness's C plane. IG stays immediate.
3. **The harness enables `BLURAY_PLAYER_SETTING_DECODE_PG`**, which libbluray needs before it decodes PG and which also sets PSR2's display flag; the replay makes the same PSR2 write before First Play (untraced).

## Review Focus

1. **A seek while a subtitle is on screen.** The subtitle disappears at once, no subtitle from before the seek reappears, and the next one after the target shows on time. Task 4 has a test.
2. **Switching PG streams while one is on screen.** The old stream's subtitle goes at once and the new stream's current subtitle appears without waiting for a far epoch. Task 4 has a test.
3. **Subtitles Off on a stream whose display sets mix forced and normal objects.** Only the forced objects are drawn, and they clear when their display set ends. Task 2 has a test.
4. **SRT edge cases:** overlapping cues, cues past the end of the playlist, a negative offset that moves cues before zero, a file of 50 000 cues. No crash, correct cues shown, and drawing stays cheap (binary search, no per-frame scan). Tasks 6 and 7 have tests.
5. **Opening another disc or picking a raw playlist with a text track loaded or a PG subtitle shown.** The text track is dropped with the disc (kept across playlists of the same disc), the PG plane clears, and nothing from the old disc is drawn. Task 8 has a test.

export interface PgUnit { readonly data: Uint8Array; readonly ptsUs: number; readonly dtsUs?: number }   // playlist time
export interface PgStreamControlDeps {
  readonly regs: RegisterFile;
  /** The UO mask in force (the navigator's), or none. */
  isMasked(op: UoOp): boolean;
  /** PSR2 now names another PID (or none): the player restarts the pipeline at the current time. */
  pidChanged(pid: number | null): void;
}
export class PgStreamControl {
  constructor(deps: PgStreamControlDeps);
  readonly plane: OverlayPlane;               // buffered, 1920×1080, resized from the video descriptor
  /** _init_pg_stream after a play item opens; with `ownPsrs`, also the PG part of _update_clip_psrs. */
  playItemStarted(item: PlayItem, ownPsrs: boolean): void;
  /** The PID to demux now, or null. */
  get pid(): number | null;
  push(unit: PgUnit): void;
  /** Decodes due units (DTS ≤ clock) and renders display sets whose PTS ≤ clock. */
  tick(clockUs: number): void;
  /** A seek: drop queued units and pending sets, discardPartial, and reset the renderer (the plane clears). */
  seek(): void;
  /** _select_pg_textst_stream: 'off' clears the display flag, {pg: n} sets stream n and the flag; false if masked or invalid. */
  select(choice: { readonly pg: number } | 'off'): boolean;
  /** Tracks of the current play item. */
  tracks(): Array<{ readonly index: number; readonly language: string }>;
  /** PSR2 stream (1-based, 0 none) and display flag. */
  get selection(): { readonly stream: number; readonly display: boolean };
  get errors(): number;
  /** The last render: objects drawn and how many were forced; null before any. */
  get shown(): { readonly objectsShown: number; readonly forced: number } | null;
  /** Closes the plane and forgets the stream (disc closed). */
  stop(): void;
}

### Task 4: PG in the player

**Files:** Modify `src/engine/playback/pipeline.ts`, `src/engine/playback/stream-selection.ts`, `src/engine/player.ts`, `src/engine/protocol.ts`, `src/engine/render/compositor.ts`. Tests: `pipeline.test.ts`, `player.test.ts`, `compositor.test.ts`.

**Behaviour:**
- **Pipeline:** a `pg?(unit)` sink and `setPgStream(pid: number | null)`; PG PES of that PID go to the sink with playlist-time PTS and DTS (like `ig`). `pgEntryFor` in `stream-selection.ts` is not needed: the PID comes from `PgStreamControl.pid`.

### Task 6: SRT decoding and parsing

**Files:** Create `src/engine/subs/srt.ts`. Test: `src/engine/subs/srt.test.ts`.

**Interfaces (produces):**
```ts
export interface StyledRun { readonly text: string; readonly italic: boolean; readonly bold: boolean; readonly underline: boolean; readonly color: string | null /* CSS colour */ }
export interface TextCue { readonly startUs: number; readonly endUs: number; readonly lines: readonly (readonly StyledRun[])[]; readonly align: 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 }
export type DecodeResult = { readonly text: string } | { readonly needsEncoding: true };
/** BOM (UTF-8, UTF-16 LE/BE), then strict UTF-8, then `fallback` (a TextDecoder label); needsEncoding if all fail or none given. */
export function decodeText(bytes: Uint8Array, fallback?: string): DecodeResult;
export interface SrtParse { readonly cues: readonly TextCue[] /* sorted by start */; readonly skipped: number; readonly blocks: number }
export function parseSrt(text: string): SrtParse;
/** The cues active at `timeUs`, in start order; binary search over the sorted cues plus the longest-cue window. */
export function activeCues(cues: readonly TextCue[], timeUs: number): TextCue[];
```

Tags: `<i> <b> <u>` (and closing), `<font color="#rrggbb">`/`<font color="name">`, `{\anN}` anywhere in the cue (last one wins); other `<…>` and `{…}` tags are removed; `&amp; &lt; &gt;` decode. Times `HH:MM:SS,mmm` or `.mmm`, hours may exceed 99; a cue whose end ≤ start is skipped.
